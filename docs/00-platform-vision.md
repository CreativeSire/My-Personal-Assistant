# Victor Platform Vision

Victor is a reusable personal-AI platform with two equal interfaces (`Telegram` and `Desktop`) and one shared control plane.

Core goals:
- Own data and telemetry.
- Safe high-autonomy with hard deny zones.
- API-compatible boundary for external apps (Dala and future clients).
- Progressive migration from API-heavy reasoning to local routine intelligence.

Phase progression:
1. Data Engine + boundary stabilization.
2. Agent framework and tool parity.
3. Learning loop with PyTorch-based model refinement.
